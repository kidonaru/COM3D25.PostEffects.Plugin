# 輪郭の色にじみ

COM3D2.5 向けに実装・ビルド・実機検証・ゲーム配置を完了（2026-09-08）。ゲームを再起動すると使用できる。

## 使い方

1. PostEffects の「輪郭・線画」カテゴリから「輪郭の色にじみ」を選ぶ。
2. 有効にし、「混ぜ具合」と「参照距離 (px)」を調整する。初期値は 0.6 と 2 px。
3. 必要に応じて「彩度」「指定色の割合」「指定色」を調整する。
4. 「対象の線を表示」で対象を確認できる。通常表示へ戻すときは OFF にする。

現在のブルーム設定とキャラの材質設定は変更していない。まず輪郭側の色にじみを調整し、必要に応じてブルームの強さ・広がりを別途調整する。

## 動作

標準トゥーン材質の元の `OUTLINE` パスを、不透明物描画直後のカメラ深度に対して別の色テクスチャへ描く。そのアルファを輪郭の被覆率として使うため、黒い輪郭も拾える。元の材質、線幅、輪郭テクスチャを書き換えず、髪が顔に重なる内部の線も対象になる。

マスクとカメラの解像度・MSAA サンプル数を揃え、元のカメラ深度はクリアしない。近傍 8 方向から線の外側・明るい色を優先して集め、マスク部分だけに混ぜる。線の外側と元画像のアルファは変更しない。

効果は不透明描画段階のポストエフェクトである。後続のブルーム等は合成後の画像を処理し、半透明物や UI は通常どおり上から描かれる。

## 対応範囲

- COM3D2.5 の通常カメラ、標準の `CM3D2/Toony_Lighted` 系の輪郭付き不透明材質。
- 非表示レンダラー、影だけのレンダラー、カメラ対象外レイヤーは除外。
- NPR 等の別系統シェーダー、テクスチャに描かれた線、半透明キューへ移した材質、VR ステレオ描画は対象外。
- COM3D2（2.0）は従来機能のビルドを確認したが、新機能の登録は行っていない。Unity 5.6 がライセンス未認証で新しいシェーダーバンドルを生成できないため。既存の 2.0 用バンドルは変更していない。

## 検証結果

| 検証 | 結果 |
|---|---|
| COM3D2.5 Release C# ビルド | 成功 |
| COM3D2 Release C# ビルド（従来機能） | 成功 |
| Unity 2022.3 シェーダーバンドル | 成功、実行時 `isSupported = true` |
| 実際のキャラの輪郭 | 顎・髪・衣装の 7 描画を取得、通常合成と対象線表示を目視確認 |
| シェーダーの隔離テスト（16×16 画素） | 線内 16 画素のみ変化、線外 0 画素、アルファの変化 0 画素 |
| 混ぜ具合 0 | 元画像との差分 0 画素 |
| 設定の XML 保存・復元 | 強度 0.73、距離 3.5 の復元を確認 |
| 古いプリセット | 新機能は既定の無効状態になる |
| 既定設定の保存 | 新設定は XML から省略される |
| 解像度と MSAA の変更 | 512×256 / 1 サンプル → 1024×512 / 2 サンプルへの再作成を確認 |
| 無効化・再有効化 | マスク解放、CommandBuffer の登録解除を確認、再有効化後も描画可能 |
| 最終クリーンアップ | 検証用エフェクト 0、輪郭マスク 0、描画登録 0 |
| ゲームへの配置 | DLL・バンドルともビルド成果物と SHA-256 一致 |
| 差分の空白検査 | `git diff --check` 成功 |

実機テストは一時的に読み込んだ検証用アセンブリで実施した。新しい設定画面を含む通常起動での確認にはゲーム再起動が必要。

## 配置

同梱成果物:

- `UnityInjector (COM3D2.5)/COM3D25.PostEffects.Plugin.dll`
- `UnityInjector (COM3D2.5)/Config/PostEffects/Shaders/posteffects`

ゲーム側は `W:/COM3D2_5/Sybaris/UnityInjector/` へ配置済み。起動中の旧 DLL は直接上書きできなかったため、`COM3D25.PostEffects.Plugin.dll.before-outline` に退避し、新 DLL を元の名前で配置した。

更新前の DLL とバンドルのバックアップはリポジトリ内 `output/outline-deploy-backup/` に保存している。
